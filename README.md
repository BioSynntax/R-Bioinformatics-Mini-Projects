## 🧬 01. BRCA1 Sequence Analysis

Analysis of the **BRCA1 (BRCA1 DNA Repair Associated)** gene using R and Bioconductor.

### 🔬 Key Analyses

* Retrieval of nucleotide sequence
* Sequence length determination
* ATG codon identification
* Reverse complement generation
* Genomic coordinate analysis
* Gene identification and annotation

### 🛠️ Tools & Packages

`R` · `Biostrings` · `GenomicRanges` · `AnnotationDbi` · `org.Hs.eg.db` · `rentrez`

📁 **Project:** `01_BRCA1_Sequence_Analysis/`

## 📊 03. Statistical Analysis in R

Application of statistical methods and visualization techniques to biological and educational datasets.

### 🌱 PlantGrowth Dataset

The built-in R **PlantGrowth** dataset was analyzed to compare plant weight across control and treatment groups.

**Methods:**

* Descriptive statistics
* Group-wise mean and standard deviation
* One-way ANOVA
* Boxplot
* Violin plot
* Histogram

**ANOVA:** `p = 0.0159`

### 🎓 Student Marks Dataset

A student dataset was analyzed using descriptive and correlation-based methods.

**Methods:**

* Mean and median
* Standard deviation
* Minimum and maximum values
* Gender-wise analysis
* Pearson correlation
* Scatter plot
* Linear regression

### 🛠️ Tools

`R` · `Base R` · `ggplot2`

📁 **Project:** `03_Statistical_Analysis_R/`
